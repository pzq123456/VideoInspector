# 模型: models/vest/vest_dyn_fp16.engine（FP16 动态 batch 1~12，已预构建）
#   输入 [B,3,640,640] RGB，输出 [B,300,6]（post-NMS）
#   每行 = [x1,y1,x2,y2,conf,cls]；cls: 0=vest(已穿), 1=no_vest(未穿)
#   原始 ONNX（models/vest/vest.onnx）为 ultralytics NMS 导出，仅重建引擎时使用。
# 解析: models/vest/libnvdsinfer_custombboxparser_vest.so
#   → 与 helmet 解析器完全同源（导出符号 NvDsInferParseCustomHelmet），
#     因输出格式同为 [N,6] end2end，直接复用，parse-bbox-func-name 不变。
#   → NMS 已烧入模型，cluster-mode=4（不二次 NMS）
#
# 说明: 整帧检测器，作为 process-mode=1，紧跟在 pgie(yolo26n) 与 helmet 之后
#   对同一帧独立检测，结果以 uid=4 挂在帧级；探针再按「框中心是否落在 person
#   框内」做空间关联，得到逐人反光衣状态（冲突时 no_vest 优先）。
#
# 路径约定: 所有模型路径均为「相对项目根目录」，服务启动时由 server/main.py
